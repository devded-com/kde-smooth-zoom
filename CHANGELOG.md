# Changelog

## 1.0.0 — 2026-10-23

- First public release.
- One-command installer for KDE Plasma 6.
- Plasma applet: toggle, zoom step, pointer tracking, scroll modifier, reset.
- Apple-like preset: `Super` + wheel, pointer-anchored, 1.15× per step.
- `smooth-zoom` CLI: status, on/off/toggle, reset, set, preset, settings.
- Desktop launchers for toggle and Accessibility → Zoom.
- Safe backup/restore of the KWin settings changed by the installer.
